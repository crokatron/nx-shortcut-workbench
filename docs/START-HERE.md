# NX Shortcut Workbench: start here

**Continuing this tool? Read [the detailed handover](HANDOVER.md).** For pictures and operation, use the [manual](USER-MANUAL.md) and [offline demo](../demo.html).

Find commands, assign and check shortcut conflicts, and prepare role/macro-pad exports. Exporting a role is separate from importing it into NX.

**Start with:** Find a command. Type a name such as Extrude into Search all commands. Review both the displayed label and command identifier: similarly named commands can belong to different workflows.

**Source:** this is a private source checkpoint, not a live-system mirror. Check [the source manifest](../SOURCE-MANIFEST.json) and current working files before merging.

**Keep your work safe:** Keep the original .mtx, the edited export and any workbench draft separately. Browser drafts can disappear when site data is cleared. Role files and macro-pad exports are different deliverables.

**Next maintainer action:** Round-trip a copied role and verify command IDs/conflicts in the intended NX version and modules. Test macro-pad output on its actual firmware; keep existing roles recoverable and retain vendor attribution and rights notices.
